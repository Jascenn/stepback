# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's **Security > Advisories > Report a vulnerability** flow:

https://github.com/Jascenn/stepback/security/advisories/new

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include real API keys, access tokens, or personal health
information in the report.

Reports are handled on a best-effort basis. Please allow time for validation
and a coordinated fix before public disclosure.
